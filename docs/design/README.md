## Regras de ouro

1. Tema escuro obrigatório. Nunca modo claro.
2. Neon é funcional, não decorativo — cada cor tem significado.
3. Nenhum texto essencial dentro de imagens. Texto é sempre UI.
4. Nenhum resultado de jogo decidido no cliente. Interação visual dramatiza rolagens do servidor.
5. São Paulo 2087, não Night City nem Neo Tokyo: concreto, garoa, funk, pastel, vela de santo, verticalidade.
