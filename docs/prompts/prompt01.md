# Tarefa: Pesquisar sobre jogos no estilo rpg multiplayer simples com alta taxa de retencao

## Objetivo

Realise uma pesquisa de produto, sobre este jogo [The Crims](https://www.thecrims.com/).

- Precisamos entender todas as mecanicas, features, requisitos e PRD para criar o nosso produto.
- Precisamos também buscar outros jogos parecidos que fizeram tanto sucesso quanto, inclusive com outras tematicas, mas que se baseiam em mecanicas e jogabilidade parecidas.
- Nossa prioridade é um jogo barato para construir, manter e escalar. Deve ter alta taxa de retencao e alto fator replay como principais indicativos de sucesso.
- Para cada jogo pesquisado, precisamos analisa-lo como um produto e o porque ele fez sucesso, com cada insight, fatores ou mecanicas que tornaram ele um jogo com alta retencao ou fator replay. E como tudo se conecta.

## Criterio

Ao fim voce deve criar todos os arquivos resultantes de nossa pesquisa em `./docs/pesquisa-de-mercado`.
